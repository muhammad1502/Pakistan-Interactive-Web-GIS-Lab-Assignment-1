# Pakistan Atlas — Lab Assignment 1

An interactive Web GIS of Pakistan created for the Web GIS Application course.

- **Assignment:** Lab Assignment 1 — Develop an Interactive Web GIS of Pakistan
- **Student:** Muhammad Abdullah
- **Live application:** https://pakistan-interactive-web-gis-lab-as.vercel.app

## Requirements covered

- OpenStreetMap and satellite imagery basemaps
- 20 cities with name, province/administrative area, and type
- 20 weather stations with station name, temperature, and rainfall
- Popups, zooming, panning, layer controls, and independent layer visibility
- Custom header, responsive map size, marker symbols, popup design, and page title
- Responsive light/dark interface inspired by the visual system of Assignment 1

## Run

Open `index.html` in a modern browser. An internet connection is required for Leaflet and map tiles.

Weather values are a static educational dataset for demonstrating Web GIS interaction; they are not live observations.
